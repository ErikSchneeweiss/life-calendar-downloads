# Life Calendar für macOS

Hier werden ausschließlich fertige App-Downloads, Versionshinweise und die signierte Update-Liste veröffentlicht. Der Quellcode bleibt in einem separaten privaten Repository. Dieses Repository enthält keine Kalenderdaten, Anmeldedaten oder privaten Sicherungen.

## Downloads

Noch kein allgemein installierbares App-Paket veröffentlicht. Die bisherige Entwicklungsversion ist für einen einzelnen Test-Mac signiert. Ein Download für weitere Macs wird erst nach Klärung und Prüfung der Verteilung bereitgestellt.

## Updates

Ab Version 0.8.0 ist die Update-Suche im Mac-Menü **Life Calendar → Nach Updates suchen …** vorbereitet. Sobald hier ein geeignetes Update veröffentlicht ist, kann die App es herunterladen und nach Bestätigung installieren. Ein GitHub-Konto ist dafür nicht erforderlich. App-Pakete und Update-Liste werden auf ihre digitale Signatur geprüft.

## Datenschutz

Das Herunterladen der App gewährt keinen Zugriff auf Kalender anderer Personen. Gemeinsame Kalender erfordern eine Anmeldung und eine ausdrücklich erteilte Freigabe. Private Kalender bleiben privat.
